# 项目上下文摘要

- 基线：Cockpit `v1.18.2`，分支 `feature/power-control`。
- 顺序：M3 后先完成 L1 汉化基础与核心界面、L2 全界面汉化，再进行 M4 真实设备联调和 M5 稳定交付。
- 门禁：每个里程碑必须测试、交付并由用户人工确认，才能开始下一步。
- 目标：新增 1～32 路电源控制 Widget，通道数量人工输入、名称可编辑，每路提供开启/关闭按钮，以寄存器读回值确认实际状态。
- 状态色：实际开启时开启按钮为绿色 `#2e7d32`；实际关闭时关闭按钮为红色 `#c62828`。
- 通信：Electron 主进程通过 TCP Server 发送 Modbus RTU 帧，界面通过类型化 IPC 调用；浏览器 Widget 不直接建立原始 TCP 连接。
- 可靠性：请求串行、CRC16、超时、拆包/粘包、异常码、重连、1 秒轮询、3 秒离线。
- 未决输入：真实设备寄存器表或已验证报文，M4 前必须提供。
- 当前状态：M0、M1、M2、M2.5、M3、L1 已通过人工验收，L2 正待启动。TCP Server 地址、端口、从站地址和超时已持久化，并作为 M3、M4 的正式连接基础；L2 人工验收前不得启动 M4。

Codex 原始会话只保留在系统会话目录，不复制进工程。
